# Vista

An application created to replace easyworship in our church, since EasyWorship wasn't providing the features we mainly needed. 
### The main feature provided here is the output window supporting no background color, so it's easy to display contents on OBS without blocking anything below it.
This is all we wanted from Easyworship and didn't find. so here we are

# Features: 
- Nyimbo Za Kristo songs are built in by default. With possibility to add Hymns and other forms of lyrics
- Offline-first approach. The app is offline, once installed can display the lyrics without needing an internet connection



# Upcoming features
- Space for displaying announcements (text that can be typed and displayed.)
- Run the controller window on a different machine from the output window. This could enable multiple people collaborating to do different tasks in the media room setting instead of having one computer be used for switching stuff on OBS and still switching stuff on Vista (which can be demanding when worshipping)
- Build an online store for lyrics for popular books like songbooks in local languages, Bibles and own composition songs

- Auto-scroll. Not sure yet how I would do it, but it will be great to  have this feature especially for own compositions by setting the appropriate tempo that's being used and see the lyrics change on their own. 
**This might require us to turn this simple app into a music sheet and use sheet timing for scrolling**
