# Documentation site

This folder contains the content for a simple documentation landing page for Vista.

## Publish it

The easiest way to publish it is to host the docs folder as a static site on GitHub Pages, Netlify, or any web host that serves static files.

### GitHub Pages

1. Push the repository to GitHub.
2. In the repository settings, enable GitHub Pages.
3. Choose the docs folder as the site source.
4. Your site will be available at a public URL.

### Netlify

1. Create a new site from your repository.
2. Set the publish directory to docs.
3. Deploy.

### External linking

Once published, you can link to the landing page from websites, church portals, download pages, or internal dashboards using the public URL.
