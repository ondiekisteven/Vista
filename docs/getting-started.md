# Getting Started

## Requirements

- Windows 10 or newer
- A second display is recommended for presenting lyrics
- No account is required
- The app stores its data locally on the machine

---

## Installation

1. Download the latest Windows release.
2. Run the installer and follow the prompts.
3. Launch Vista after installation completes.
4. Prepare your song library in the app.
5. Open the output window and present your first song.

---

## First launch

On first run, Vista creates its local settings folder under your Windows user profile. This keeps the software self-contained and makes it easy to run in a church environment without cloud services.

---

## Your first service

1. Search for a song in the library.
2. Select the song to preview its slides.
3. Send it to the output window.
4. Use the slide navigation keys to move through the service.

If you want to change the look of the displayed text, open the output settings and adjust the size, background, or transparency options.
