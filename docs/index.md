# Vista

Vista is a Windows desktop worship presentation app for churches. It helps a service team search songs, preview lyrics, and send them to a second display with a clean, readable output.

## Why Vista?

- Built for live worship services
- Runs locally with no account required
- Search songs quickly from your library
- Present lyrics to a second screen
- Adjust output size and background appearance
- Designed to stay simple during a service

---

## What it does

Vista gives operators a lightweight control screen for selecting songs and sending their lyrics to an output window. The interface is intentionally simple so that the team can focus on leading worship rather than troubleshooting software.

---

## Quick start

1. Download the latest release for Windows.
2. Install the application.
3. Open Vista and load your song library.
4. Select a song, preview it, and present it to your output display.

For the full setup walkthrough, see [Getting Started](getting-started.md).
