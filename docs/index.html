Vista

Vista is a Windows worship presentation app for churches. It helps a service team search songs, preview lyrics, and send them to a second screen with a clear, readable output.

Built for live worship

Keep the workflow simple during a service with a focused interface for song selection and presentation.

Local-first

Readable output
