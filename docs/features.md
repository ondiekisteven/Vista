# Features

## Song library

- Search songs quickly by title or lyrics
- Browse a local library of worship songs
- Preview the full slide structure before presenting

---

## Presentation output

- Send lyrics to a dedicated output window
- Use a second screen for the congregation
- Control slide flow from the main app

---

## Output settings

- Adjust output width and height
- Choose a transparent or solid background
- Change the background color for better contrast
- Tune minimum and maximum font size

---

## Simple workflow

Vista is designed to stay out of the way during a service. The interface is focused on a few key tasks: find a song, preview it, and present it.

---

## Local-first design

Everything is stored locally, which makes the app easier to manage in a church environment and reduces the need for internet connectivity during services.
